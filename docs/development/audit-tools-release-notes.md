公開監査資料を手元で確認するためのツールです。`audit-viewer.zip` を展開して `index.html` をブラウザで開いてください。資料をサーバーへ送信せず、オフラインで利用できます。

CLI、ソース、形式仕様、検証用サンプル、操作説明、ライセンスを同梱しています。CLIにはNode.js 22.17以降が必要です。ブラウザの動作確認対象はChromiumです。

`SHA256SUMS` は配布ファイルのSHA-256です。ハッシュ一致はファイルの同一性の確認であり、分析の正確性や発行者の身元を保証するものではありません。資料の署名を確認する場合は、別の信頼できる経路で確認した公開鍵を使ってください。
