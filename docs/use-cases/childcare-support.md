# 子育て支援アンケート

子育て支援施策に関する自由記述アンケートを整理するユースケースです。

## 想定する場面

- こども計画や子育て支援事業計画の検討
- 子育て世帯向けアンケートの自由記述整理
- 子育て支援センター、保育、相談窓口の改善検討

## 入力データ

サンプルCSVには、以下の列を含めています。

| 列 | 内容 |
| --- | --- |
| `id` | 回答ID |
| `comment` | 自由記述コメント |
| `child_age` | 子どもの年齢区分 |
| `area` | 居住地区 |

- [サンプルCSVをダウンロード](samples/childcare-support.csv)
- [サンプルレポートを見る](https://kouchou-ai-sample-viewer.vercel.app/childcare-support/)

## レポートの読み方

まず、上位クラスタで以下の3点を確認します。

- 預かり先と時間: 一時預かり、病児保育、休日・夕方対応
- 情報の見つけにくさ: 制度情報、イベント情報、手続き情報の探しやすさ
- 相談と孤立: 気軽な相談先、転入者や孤立しがちな家庭への接点

その後、子どもの年齢や地区で属性フィルターを使い、どの層にどの課題が強く出ているかを確認します。制度を増やすべき課題と、既存制度の周知・導線整理で改善できる課題を分けて読むと、次の検討につなげやすくなります。

## 次のアクション例

- 年齢区分ごとに、預かり・情報・相談の論点を整理する
- 既存制度の周知不足と、制度そのものの不足を分けて検討する
- 孤立しやすい家庭に届く相談導線を、オンラインと対面の両方で設計する
