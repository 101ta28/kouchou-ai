# パブリックコメント整理

条例、計画、施設使用料などの見直し案に寄せられたパブリックコメントを整理するユースケースです。

## 想定する場面

- パブリックコメント募集後の意見整理
- 回答案や修正要否の庁内検討
- 議会説明、住民説明、結果公表資料の準備

## 入力データ

サンプルCSVには、以下の列を含めています。

| 列 | 内容 |
| --- | --- |
| `id` | 意見ID |
| `comment` | 自由記述コメント |
| `position` | 賛否や論点の種別 |
| `stakeholder` | 意見提出者の立場 |
| `channel` | 提出経路 |

- [サンプルCSVをダウンロード](samples/public-comment.csv)
- [サンプルレポートを見る](https://kouchou-ai-sample-viewer.vercel.app/public-comment/)

## レポートの読み方

まず、上位クラスタで以下の3点を確認します。

- 負担の公平性: 受益者負担への理解、値上げ幅への懸念
- 利用者への影響: 子育て団体、高齢者団体、低所得者などへの影響
- 説明と制度設計: 算定根拠、減免、周知期間、代替案への要望

パブリックコメントでは、賛否の数だけで判断しないことが重要です。少数でも制度上の不備や説明不足を指摘している意見は、回答案や修正案の検討対象になります。属性列を使い、どの立場からどの論点が出ているかを確認してください。

## 次のアクション例

- 論点ごとに回答案を作り、原文と照合する
- 修正が必要な論点と、追加説明で対応できる論点を分ける
- 減免、段階導入、周知期間など、制度設計上の選択肢を庁内で比較する
