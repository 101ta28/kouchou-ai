# パブリックコメント整理

条例、計画、再生可能エネルギー施設整備案などに寄せられたパブリックコメントを整理するユースケースです。

## 想定する場面

- パブリックコメント募集後の意見整理
- 回答案や修正要否の庁内検討
- 議会説明、住民説明、結果公表資料の準備

## 入力データ

サンプルCSVには、以下の列を含めています。

| 列 | 内容 |
| --- | --- |
| `id` | 意見ID |
| `comment` | 自由記述コメント |
| `position` | 賛否、条件付き賛成、慎重意見、説明不足などの種別 |
| `stakeholder` | 意見提出者の立場 |
| `channel` | 提出経路 |

- [サンプルCSVをダウンロード](samples/public-comment.csv)
- [サンプルレポートを見る](https://kouchou-ai-sample-viewer.vercel.app/public-comment/)

## レポートの読み方

まず、上位クラスタで以下の3点を確認します。

- 環境・景観への配慮: 生態系、里山、観光景観、既存施設活用への意見
- 防災・安全管理: 災害時電源への期待、土砂災害・水害・維持管理への懸念
- 地域還元と説明責任: 地元経済への還元、住民説明、情報公開、合意形成への要望

パブリックコメントでは、賛否の数だけで判断しないことが重要です。少数でも制度上の不備や説明不足を指摘している意見は、回答案や修正案の検討対象になります。属性列を使い、どの立場からどの論点が出ているかを確認してください。

CSVは `id` と `comment` が必須です。`position`、`stakeholder`、`channel` のような属性列があると、賛否の数だけではなく、条件付き賛成や説明不足の指摘がどの立場から出ているかを確認できます。提出者属性は個人情報ではなく、論点の偏りを見るための分類に留めます。

## 次のアクション例

- 論点ごとに回答案を作り、原文と照合する
- 追加調査や計画修正が必要な論点と、追加説明で対応できる論点を分ける
- 立地、景観配慮、防災対策、地域還元、説明会運営など、計画条件の選択肢を庁内で比較する
