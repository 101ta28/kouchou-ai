# 地域交通の見直し

地域交通の見直しに関する住民アンケートやワークショップ記録を整理するユースケースです。

## 想定する場面

- 地域公共交通計画の見直し
- 路線再編やデマンド交通導入の検討
- 住民説明会、地域懇談会、アンケートの自由記述整理

## 入力データ

サンプルCSVには、以下の列を含めています。

| 列 | 内容 |
| --- | --- |
| `id` | 回答ID |
| `comment` | 自由記述コメント |
| `area` | 居住地区 |
| `age_group` | 年代 |
| `stakeholder` | 回答者の立場 |
| `channel` | 提出経路 |

- [サンプルCSVをダウンロード](samples/local-transport.csv)
- [サンプルレポートを見る](https://kouchou-ai-sample-viewer.vercel.app/local-transport/)

## レポートの読み方

まず、上位クラスタで以下の3点を確認します。

- 日常移動の困難: 通院、買い物、通学など、生活に直結する移動の困りごと
- 運行時間と乗り継ぎ: 朝夕の本数、終発、鉄道との接続
- 予約・情報提供: デマンド交通の予約方法、時刻表や運休情報の分かりやすさ

その後、属性フィルターで地区や年代ごとの違いを確認します。たとえば、高齢者の通院・買い物の課題と、学生の帰宅時間の課題は、同じ「移動困難」でも必要な施策が異なります。

CSVは `id` と `comment` が必須です。`area`、`age_group`、`stakeholder`、`channel` のような属性列があると、どの地域・利用者層・提出経路に論点が偏っているかを確認できます。同じ文章で行数を増やすより、異なる利用場面や時間帯が分かる自由記述を入れることが重要です。

## 次のアクション例

- 地区別に主要論点を整理し、地域懇談会の議題にする
- 路線再編で対応する論点と、デマンド交通・情報提供で対応する論点を分ける
- 少数意見に見えるが生活影響が大きい論点を、追加ヒアリングで確認する
