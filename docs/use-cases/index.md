# ユースケースとサンプルレポート

このページでは、広聴AIを自治体・団体の業務で使う場面を想定したサンプルを紹介します。

サンプルレポートサイトは閲覧専用です。CSVアップロード、レポート生成、APIキー入力はできません。実データではなく、利用イメージを説明するための架空データを掲載しています。

## まず見るもの

1. ユースケースの説明を読む
2. サンプルCSVで入力データの形を確認する
3. サンプルレポートで出力イメージを確認する
4. レポートの読み方をもとに、庁内議論や追加ヒアリングの論点を考える

## サンプル一覧

| ユースケース | 想定読者 | 確認できること |
| --- | --- | --- |
| [地域交通の見直し](local-transport.md) | 企画課、交通政策担当課、地域公共交通会議の事務局 | 日常移動、運行設計、予約・情報提供に関する意見整理 |
| [子育て支援アンケート](childcare-support.md) | 子育て支援担当課、こども政策担当課、広報広聴課 | 預かり先、情報入手、相談・孤立に関する意見整理 |
| [パブリックコメント整理](public-comment.md) | 担当課、法務・文書担当、広報広聴課、議会事務局 | 賛否、懸念点、修正提案、説明不足に関する意見整理 |

## 入力データの確認

サンプルCSVの作り方や、テスト用CSVの種類は[入力データガイド](input-data-guide.md)にまとめています。

## 注意点

- サンプルは架空データです。
- 実務で利用する場合は、個人情報、未公開情報、機微情報を取り除いてから分析してください。
- AIが生成した分類や要約は、政策判断の材料の一つです。重要な判断では必ず原文と照合してください。
- レポートの価値は、AIの出力そのものではなく、人間が論点を読み解き、次の対話や検討につなげることにあります。
